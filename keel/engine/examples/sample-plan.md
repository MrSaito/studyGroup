# Sample: Two-Week Python Warm-up

## Stage 1: Foundations

### Week 1: Basics

#### Day 1: Variables and types (40 min) [learn]
**Learn:** https://docs.python.org/3/tutorial/introduction.html
**Do:** Write ten variables of different types and print their `type()`.
**Tip:** Use the REPL, not a file.

#### Day 2: Lists and dictionaries (45 min) [learn]
**Learn:** Tutorial §5.1 and §5.5
**Do:** Build a dict of five countries → capitals; add, delete, iterate.

#### Day 3: Build a word counter (60 min) [build]
**Do:** Script that reads a text file and prints the 10 most common words.
**Deliverable:** `wordcount.py` committed.

#### Day 4: Review week 1 (30 min) [review]
**Do:** Re-read your three logs. Rewrite the word counter from memory.

#### Day 5: Buffer [buffer]

### Week 2: Functions

#### Day 6: Functions and scope (45 min) [learn]
**Learn:** Tutorial §4.7
**Do:** Refactor the word counter into three functions.

#### Day 7: Error handling (45 min) [learn]
**Learn:** Tutorial §8
**Do:** Make the word counter fail gracefully on a missing file.

#### Day 8: Build a CLI (60 min) [build]
**Do:** Add argparse; support `--top N`.
**Deliverable:** `wordcount.py` with a `--help` that works.

#### Day 9: Stage 1 checkpoint (45 min) [review] [checkpoint]
**Do:** From a blank file, write a function that returns the N most common words in a string. No references.
